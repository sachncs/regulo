# Brand and logo usage

The regulo mark combines a covariance ellipse, a regularization curve, and
three reproducibility/measurement nodes. It is supplied in one canonical SVG
at `assets/logo.svg`; the site copies that asset to `site/public/logo.svg` and
uses it for the inline navigation mark.

- Use the full-colour mark on graphite or white backgrounds.
- Preserve clear space equal to one node diameter on every side.
- Do not render below 20 px without testing legibility.
- Use `assets/favicon.svg` for 16–64 px browser contexts.
- For monochrome contexts, use the white curve/ellipse on graphite; never
  recolour the yellow measurement node as a status indicator.
- Social cards should use the mark with the wordmark and a short product
  description, not the favicon alone.
